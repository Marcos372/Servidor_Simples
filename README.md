# Servidor Simples com Node.js

Projeto desenvolvido para praticar os primeiros conceitos de servidor e rotas utilizando Node.js.

##  Funcionalidades

* Criação de servidor HTTP
* Rota `/`
* Rota `/usuarios`
* Resposta simples no navegador

##  Conceitos praticados

* Node.js
* HTTP
* Rotas
* Request e Response
* Servidor local
* Métodos HTTP básicos

##  Tecnologias utilizadas

* JavaScript
* Node.js

##  Como executar

1. Instale o Node.js
2. Abra o terminal na pasta do projeto
3. Execute:

```bash id="bfx26o"
node app.js
```

4. Abra o navegador e acesse:

```plaintext id="vnsph0"
http://localhost:3000
```

##  Resultado esperado

Ao acessar a rota principal:

```plaintext id="s5vvl6"
Olá mundo
```

##  Objetivo do projeto

Praticar a criação de servidores e entender como funcionam rotas e requisições HTTP no backend com Node.js.
